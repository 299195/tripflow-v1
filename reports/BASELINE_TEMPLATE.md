# TripFlow V1 评测报告

- 数据版本：`synthetic-v1`
- API 模式：`fixture`（当前基线不调用真实高德 API）
- 生成时间：运行 `python eval/run_eval.py --report reports/latest.json` 后填写
- 被测实现/提交：待填写

## 指标口径

每个指标必须写出：分子、分母、条件、数据版本、是否真实 API。

| 指标 | 分子 | 分母 | 条件 | 数据版本 | 真实 API |
|---|---:|---:|---|---|---|
| 场景契约通过率 | `PASS` 场景数 | 全部场景数 | 状态和 reason_code 均精确匹配 | synthetic-v1 | 否 |
| 执行覆盖率 | 实际调用的场景数 | 全部场景数 | Adapter 可加载且完成调用 | synthetic-v1 | 否 |

## 场景清单

Fixture 包含：正常多地点规划、固定预约冲突、路线失败、字段缺失、模糊地点、停留过长、删除地点、替换地点、延长活动、历史版本恢复、重复请求、超时、无可行行程。

## 结果规则

没有业务 Adapter 时，场景标为 `NOT_EXECUTED`，不是通过；这表示基线已建立但业务实现尚未接入。失败案例必须保留场景 ID、实际结果、期望结果和错误详情。
