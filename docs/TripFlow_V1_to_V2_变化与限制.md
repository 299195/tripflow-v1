# TripFlow V1 到 V2 变化与限制

## 已完成变化

- 规划器支持结构化路线元数据和高德路线 provider。
- 新增路线缓存、重规划 proposal、Agent 运行记录和反馈/策略表。
- 新增延误、地点关闭、跳过地点的预览与确认流程。
- 新增版本差异、重规划候选方案和前端恢复入口。
- 新增意图、地点核验、方案审查三个可回放节点。
- 新增反馈样本生成、策略比较和硬约束发布门槛。
- 新增 40 个真实本地业务链路场景。

## 仍然受限的能力

- 首个真实路线模式是步行。
- 实时外部 API 受账号权限、网络和限流影响。
- 多 Agent 的默认节点在模型不可用时使用确定性 fallback。
- 自进化是离线评测和人工审批，不是在线自动训练或自动改代码。
- 单用户和 SQLite 边界仍保留在 V2。
- 尚未接入真实预订、支付、天气和后台 GPS 监控。
